# Store listing (한국어)

Translation of the English master listing (D-22); have a native speaker review it before publishing. The store name still waits on the trademark check (OQ-7).

## App name (max 30)

Lingo Mate: 말하고 번역

## Short description (max 80)

대화, 강의, 회의를 실시간 음성 번역. 오프라인에서도 작동합니다.

## Full description (max 4000)

누구와도 대화하고, 어떤 강의든 따라가고, 회의에서도 뒤처지지 마세요. 인터넷이 없어도 괜찮습니다. 모든 대화가 다시 쓸 수 있는 문장이 됩니다.

대화
휴대폰을 두 사람 사이에 두세요. 각자 자기 쪽을 탭하고 말하면, 상대방은 바른 방향으로 번역을 읽고 소리로도 듣습니다. 자동 모드는 마이크를 켜 둔 채 누가 말하는지 알아냅니다.

듣기
강의, 투어, 안내 방송. 내 언어로 된 실시간 자막을 크고 읽기 쉽게 보여 주며 화면은 켜진 상태로 유지됩니다.

회의
노트북으로 Zoom, Meet, Teams에 참여하고 휴대폰을 스피커 옆에 두세요. 자막이 다른 앱 위에 떠 있고, 답변 제안이 복사할 수 있는 정중한 답변 3개를 추천합니다. 회의가 끝나면 핵심 용어와 할 일이 담긴 요약을 받아 보세요.

미디어
휴대폰에서 재생 중인 동영상과 팟캐스트에도 자막을 보여 줍니다.

오프라인 작동
언어 팩을 다운로드하면 해외에서도, 비행기에서도, 신호가 약해도 인터넷 없이 번역할 수 있습니다. 음성 인식은 휴대폰에서 실행됩니다.

나만의 문장집
어떤 문장이든 한 번에 저장하세요. 태그, 즐겨찾기, 크게 보기, 소리 내어 듣기가 가능합니다. 간격 반복 복습(다시/어려움/좋음/쉬움)과 매일 알림으로 오래 기억하세요.

빠른 문장
식당, 택시, 호텔, 공항, 쇼핑, 건강 등. 문장을 탭하면 휴대폰이 대신 말해 줍니다.

쓰면서 배우기
원어민이라면 내 문장을 어떻게 말할지 확인하고, 상황별 대화를 연습하세요. 이름과 용어의 용어집을 만들면 번역이 내가 원하는 단어를 씁니다.

개인정보 보호 중심 설계
음성은 저장되지 않으며, 오프라인 엔진을 쓰면 휴대폰 밖으로 나가지도 않습니다. 대화 기록과 문장은 휴대폰에 남습니다. 기밀 대화에는 오프라인 엔진을 선택하세요. 광고 없음, 계정 불필요.

지원 언어: 베트남어, 영어, 일본어, 한국어, 중국어, 태국어, 인도네시아어, 스페인어, 프랑스어, 독일어. 더 많은 언어가 추가될 예정입니다. 오프라인 품질과 기능은 언어마다 다릅니다.
