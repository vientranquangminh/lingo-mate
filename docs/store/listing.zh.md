Translation of the English master listing (D-22); have a native speaker review it before publishing. The store name still waits on the trademark check (OQ-7).

## App name (max 30)

Lingo Mate：说话即翻译

## Short description (max 80)

对话、讲座、会议实时语音翻译，离线也能用。

## Full description (max 4000)

和任何人交流，跟上任何讲座，开会也不掉队，没有网络也没关系。每一次对话都会变成你可以再次使用的短语。

对话
把手机放在你们中间。每个人点按自己那一侧说话，对方就能按正确方向阅读译文并听到朗读。自动模式保持一个麦克风开启，并自动判断是谁在说话。

聆听
讲座、导览、广播：以你的语言显示实时字幕，字大易读，屏幕保持常亮。

会议
在笔记本电脑上加入 Zoom、Meet 或 Teams，把手机放在扬声器旁边。字幕浮在其他应用上方，“建议回复”会提供三条可复制的得体回答。会议结束后，生成包含关键词和待办事项的总结。

媒体
为手机上播放的视频和播客显示字幕。

离线可用
下载语言包，就能在完全没有网络时翻译：在国外、在飞机上、信号差的地方都行。语音识别在手机上运行。

你的短语本
一键保存任意一句话。添加标签、收藏、放大显示、朗读。间隔重复复习（重来/困难/良好/简单）帮你记住，还可以设置每日提醒。

快捷短语
餐厅、出租车、酒店、机场、购物、健康等：点按短语，手机就替你说出来。

边用边学
看看母语者会怎样说你的句子，练习情景对话，并为人名和术语建立术语表，让翻译使用你偏好的说法。

隐私优先
语音从不保存；使用离线引擎时，语音不会离开你的手机。转写内容和短语保存在你的手机上。保密对话请选择离线引擎。无广告，无需账号。

支持语言：越南语、英语、日语、韩语、中文、泰语、印尼语、西班牙语、法语和德语，更多语言即将推出。离线质量和功能因语言而异。

翻译对话时，请告知身边的人。
