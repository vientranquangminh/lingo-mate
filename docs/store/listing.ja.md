# Store listing (日本語)

Translation of the English master listing (D-22); have a native speaker review it before publishing. The store name still waits on the trademark check (OQ-7).

## App name (max 30)

Lingo Mate: 話して翻訳

## Short description (max 80)

会話・講義・会議をリアルタイムで音声翻訳。オフラインでも使えます。

## Full description (max 4000)

誰とでも話し、どんな講義にもついていき、会議でも置いていかれない。インターネットがなくても大丈夫。すべての会話が、また使えるフレーズになります。

会話
スマホを二人の間に置きます。それぞれ自分の側をタップして話すと、相手は正しい向きで翻訳を読み、音声でも聞けます。自動モードではマイクを開いたまま、誰が話しているかをアプリが判断します。

リスニング
講義、ツアー、アナウンスに。あなたの言語のライブ字幕を大きく読みやすく表示し、画面はオンのままです。

会議
ノートパソコンで Zoom、Meet、Teams に参加し、スマホをスピーカーの横に置くだけ。字幕は他のアプリの上に浮かび、「返答を提案」でコピーできる丁寧な返答を 3 つ提案します。会議の後は、重要な用語とアクションアイテム付きの要約を作成できます。

メディア
スマホで再生中の動画やポッドキャストにも字幕を表示します。

オフラインで使える
言語パックをダウンロードすれば、海外でも機内でも電波が弱くても、まったく通信なしで翻訳できます。音声認識はスマホの中で動きます。

あなたのフレーズ帳
どの文もワンタップで保存。タグ付け、お気に入り、大きく表示、読み上げができます。間隔反復の復習（もう一度／難しい／普通／簡単）と毎日のリマインダーで記憶に残ります。

クイックフレーズ
レストラン、タクシー、ホテル、空港、買い物、健康など。フレーズをタップすればスマホが代わりに話します。

使いながら学ぶ
ネイティブならあなたの文をどう言うかを確認したり、場面の会話を練習したり。名前や用語の用語集を作れば、翻訳があなたの好みの言葉を使います。

プライバシー重視の設計
音声は保存されず、オフラインエンジンなら端末の外に出ることもありません。文字起こしとフレーズはスマホに残ります。機密の会話にはオフラインエンジンを選んでください。広告なし、アカウント不要。

対応言語: ベトナム語、英語、日本語、韓国語、中国語、タイ語、インドネシア語、スペイン語、フランス語、ドイツ語。今後さらに追加予定です。オフラインの品質や機能は言語によって異なります。

会話を翻訳するときは、周りの人にひと言伝えてください。
