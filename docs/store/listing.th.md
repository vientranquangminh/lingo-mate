Translation of the English master listing (D-22); have a native speaker review it before publishing. The store name still waits on the trademark check (OQ-7).

## App name (max 30)

Lingo Mate: พูดแล้วแปล

## Short description (max 80)

แปลเสียงพูดสดสำหรับบทสนทนา การบรรยาย และการประชุม ใช้ออฟไลน์ได้ด้วย

## Full description (max 4000)

คุยกับใครก็ได้ ตามทันทุกการบรรยาย และไม่ตกหล่นในที่ประชุม แม้ไม่มีอินเทอร์เน็ต ทุกบทสนทนากลายเป็นวลีที่คุณนำกลับมาใช้ได้

สนทนา
วางโทรศัพท์ไว้ระหว่างคุณสองคน แต่ละคนแตะฝั่งของตัวเองแล้วพูด อีกฝ่ายจะอ่านคำแปลในทิศทางที่ถูกต้องและได้ยินเสียงอ่าน โหมดอัตโนมัติเปิดไมโครโฟนไว้และรู้ว่าใครกำลังพูด

ฟัง
การบรรยาย ทัวร์ ประกาศ: คำบรรยายสดในภาษาของคุณ ตัวใหญ่ อ่านง่าย และหน้าจอเปิดค้างไว้

ประชุม
เข้าร่วม Zoom, Meet หรือ Teams บนแล็ปท็อป แล้ววางโทรศัพท์ไว้ข้างลำโพง คำบรรยายลอยอยู่เหนือแอปอื่น และแนะนำคำตอบจะเสนอคำตอบสุภาพสามแบบให้คัดลอก หลังประชุม รับสรุปพร้อมคำสำคัญและสิ่งที่ต้องทำ

สื่อ
คำบรรยายสำหรับวิดีโอและพอดแคสต์ที่เล่นบนโทรศัพท์ของคุณ

ใช้ออฟไลน์ได้
ดาวน์โหลดแพ็กภาษาแล้วแปลได้โดยไม่ต้องเชื่อมต่อเลย: ต่างประเทศ บนเครื่องบิน หรือที่สัญญาณอ่อน การรู้จำเสียงพูดทำงานบนโทรศัพท์ของคุณ

สมุดวลีของคุณ
บันทึกประโยคใดก็ได้ในแตะเดียว ติดแท็ก ติดดาว แสดงตัวใหญ่ หรือเล่นเสียง การทบทวนแบบเว้นระยะ (อีกครั้ง / ยาก / ดี / ง่าย) ช่วยให้จำได้ พร้อมการแจ้งเตือนรายวัน

วลีด่วน
ร้านอาหาร แท็กซี่ โรงแรม สนามบิน ช้อปปิ้ง สุขภาพ และอื่นๆ: แตะวลีแล้วโทรศัพท์จะพูดแทนคุณ

เรียนรู้ไปพร้อมกัน
ดูว่าเจ้าของภาษาจะพูดประโยคของคุณอย่างไร ฝึกบทสนทนาตามสถานการณ์ และสร้างอภิธานศัพท์สำหรับชื่อและคำศัพท์ เพื่อให้คำแปลใช้คำที่คุณต้องการ

ออกแบบเพื่อความเป็นส่วนตัว
เสียงไม่ถูกบันทึกเลย และเมื่อใช้เอนจินออฟไลน์ เสียงจะไม่ออกจากโทรศัพท์ บทถอดความและวลีอยู่บนโทรศัพท์ของคุณ เลือกเอนจินออฟไลน์สำหรับบทสนทนาที่เป็นความลับ ไม่มีโฆษณา ไม่ต้องมีบัญชี

ภาษาที่รองรับ: เวียดนาม อังกฤษ ญี่ปุ่น เกาหลี จีน ไทย อินโดนีเซีย สเปน ฝรั่งเศส และเยอรมัน และจะมีเพิ่มอีก คุณภาพและฟีเจอร์ออฟไลน์แตกต่างกันไปตามภาษา
